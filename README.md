# Planera

En iPhone-anpassad PWA för dagsschema, timers, målprogress och dagliga utgifter.

## Använd på iPhone

1. Publicera mappen på en vanlig webbplats med HTTPS (till exempel GitHub Pages, Netlify eller Vercel).
2. Öppna sidans adress i Safari på iPhone.
3. Välj Dela → Lägg till på hemskärmen.

All data sparas lokalt i den aktuella webbläsaren på telefonen. Den delas därför inte mellan enheter och försvinner om Safari-data för webbplatsen rensas.
